# 🎬 MovieBox

A beautiful **React Native movie app** built with **Expo Router**, **Appwrite**, **NativeWind**, and **TMDB API**.  
MovieBox lets users explore trending movies, search titles, view detailed movie info, and save favorites using secure Appwrite authentication.

---

## 🚀 Features

- 🔥 **Trending Movies**
- 🔍 **Search Movies**
- 🎞️ **Similar Movies Suggestions**
- ❤️ **Add to Favorites / Wishlist (Appwrite Database)**
- 👤 **User Authentication & Profile (Appwrite)**
- 📱 **Clean UI with TailwindCSS (NativeWind)**
- 🌐 **Real-time data from TMDB API**

---

## 🛠 Tech Stack

- **React Native**
- **Expo Router**
- **TypeScript**
- **Appwrite (Auth + Database)**
- **NativeWind (TailwindCSS)**
- **TMDB API**

---

## 📺 Screens

- 🏠 **Home Screen** – trending movies & categories
- 🔎 **Search Screen** – find movies instantly
- 🎬 **Movie Details Screen** – description, rating, similar movies
- ⭐ **Favorites Screen** – user-saved movies
